One joke about office life, a single line, built for the
[make.fun](https://make.fun) bounty "Make the AI Judge Laugh".

> My calendar has a meeting called 'quick sync' that has outlived two managers and one marriage.

`main.py` (Python 3, standard library only) writes the joke to
`/output/entry.txt`, deterministically.
